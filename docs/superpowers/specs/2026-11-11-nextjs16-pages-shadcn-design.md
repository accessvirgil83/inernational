# Дизайн-спецификация: Каркас Next.js 16 для сборки статики на GitHub Pages с shadcn/ui и двуязычием (RU/KK)

**Дата:** 2026-11-11  
**Статус:** Утверждено  
**Репозиторий:** `inernational` (`git@github.com:accessvirgil83/inernational.git`)  
**Пакетный менеджер:** `pnpm`  
**Целевая платформа деплоя:** GitHub Pages (`https://accessvirgil83.github.io/inernational/`)  

---

## 1. Цели и границы проекта

### 1.1. Основная цель
Создать стабильный и масштабируемый стартовый каркас на базе **Next.js 16** (App Router, React 19) с поддержкой статического экспорта (`output: 'export'`), библиотекой компонентов **shadcn/ui**, поддержкой темной/светлой темы (**next-themes**) и двуязычной структурой (**русский / казахский**). Каркас должен автоматически собираться и развертываться на **GitHub Pages** через GitHub Actions при пуше в ветку `main`.

### 1.2. Подготовка к следующему этапу
Данный каркас служит фундаментом для последующей задачи: разработка полноценного интерактивного портфолио и резюме разработчика на казахском и русском языках.

---

## 2. Архитектура и конфигурация

### 2.1. Next.js Конфигурация (`next.config.ts`)
- **Режим экспорта:** `output: 'export'` (генерация директории `out/` без SSR сервера).
- **Базовый путь (`basePath`):**
  - В `production`: `/inernational` (путь к репозиторию на GitHub Pages).
  - В локальной разработке (`development`): `""` (пустая строка для удобства локального просмотра на `localhost:3000`).
- **Префикс ассетов (`assetPrefix`):** Соответствует `basePath` в продакшене.
- **Оптимизация изображений:** `images: { unoptimized: true }` для работы статических картинок на GitHub Pages без встроенного Node.js image optimization API.
- **Генерация путей:** `trailingSlash: true` (создание страниц вида `out/ru/index.html` и `out/kk/index.html` для надежной статической маршрутизации).

### 2.2. Маршрутизация и локализация
- **Стартовый корень (`/`) (`app/page.tsx`):**
  Статическая страница приветствия с выбором языка и интерактивной мини-игрой:
  - **Интерактивная игра «Қазақ Тұлпары» (Kazakh Horse Runner):**
    - Аналог игры Chrome Dino, выполненный в степной тематике.
    - Персонаж: скачущая казахская лошадь (Тұлпар).
    - Препятствия: юрты (киіз үй), степные камни и кусты.
    - Управление: Пробел, стрелка вверх или тап/клик по экрану (поддержка мобильных устройств).
    - Счетчик очков и рекорд (с сохранением в LocalStorage).
    - Перезапуск по кнопке или пробелу.
  - Карточка с кнопками перехода к портфолио/резюме:
    - 🇰🇿 **Қазақша** → `/${basePath}/kk/`
    - 🇷🇺 **Русский** → `/${basePath}/ru/`
  - Переключатель тем оформления.
- **Языковые страницы (`app/[lang]/page.tsx`):**
  - Экспорт функции `generateStaticParams()`:
    ```ts
    export async function generateStaticParams() {
      return [{ lang: 'ru' }, { lang: 'kk' }];
    }
    ```
  - Загрузка словаря через `getDictionary(lang)`.
  - Каркас страниц портфолио/резюме:
    - Навигационная панель (`Navbar`) с переключателем языка `LanguageToggle` и переключателем темы `ThemeToggle`.
    - Hero-секция с приветствием, ролью и кнопками действий.
    - Заготовки под секции: «Обо мне», «Навыки» (с тегами-бейджами), «Проекты» (карточки проектов) и «Контакты».

## 3. UI-система и компоненты

### 3.1. Стилизация и темы
- **Стек:** Tailwind CSS, `next-themes`, `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge`.
- **Цветовая палитра:** `zinc` (нейтральная темная/светлая палитра shadcn).
- **Провайдер тем:** Обертка `ThemeProvider` на базе `next-themes` с `attribute="class"`, `defaultTheme="system"`, `enableSystem`.

### 3.2. Компоненты интерфейса
1. `src/components/ui/button.tsx` — кнопка с различными вариантами (default, outline, ghost и т.д.).
2. `src/components/ui/card.tsx` — карточки контента.
3. `src/components/ui/badge.tsx` — бейджи для стека технологий.
4. `src/components/theme-toggle.tsx` — переключатель светлая/тёмная тема.
5. `src/components/language-toggle.tsx` — переключатель языка (RU ↔ KK).
6. `src/components/navbar.tsx` — адаптивная шапка.

## 4. Словари данных

- `src/dictionaries/ru.json` — русский текст для всех секций.
- `src/dictionaries/kk.json` — казахский перевод для всех секций.
- `src/lib/get-dictionary.ts` — типизированный хелпер загрузки JSON словаря по локали (`'ru' | 'kk'`).

## 5. CI/CD деплой (`.github/workflows/nextjs.yml`)

1. **Триггеры:** `push` в ветку `main`, а также `workflow_dispatch` (ручной запуск).
2. **Права токена:** `pages: write`, `id-token: write`, `contents: read`.
3. **Этапы сборки (job: build):**
   - Чекаут репозитория (`actions/checkout@v4`).
   - Установка `pnpm` через `pnpm/action-setup@v4`.
   - Установка Node.js 20/22 с кэшем `pnpm` (`actions/setup-node@v4`).
   - Настройка страниц (`actions/configure-pages@v5`).
   - Установка зависимостей: `pnpm install --frozen-lockfile`.
   - Сборка Next.js статики: `pnpm run build` (генерирует `./out`).
   - Загрузка артефактов статики: `actions/upload-pages-artifact@v3` с путем `./out`.
4. **Этап деплоя (job: deploy):**
   - Развертывание через `actions/deploy-pages@v5` на окружение `github-pages`.

---

## 6. План валидации и проверки

1. **Компиляция TypeScript:** `pnpm tsc --noEmit` без ошибок типизации.
2. **Статическая сборка:** `pnpm run build` завершается с кодом 0 и формирует каталог `./out`.
3. **Проверка артефактов в `./out`:**
   - Наличие `./out/index.html` (стартовая страница выбора языка).
   - Наличие `./out/ru/index.html` (русская версия).
   - Наличие `./out/kk/index.html` (казахская версия).
   - Проверка наличия корректного префикса путей `/inernational/` к `_next/static/`.
4. **Локальный запуск:** `pnpm dev` корректно стартует и отвечает на запросы без ошибок гидратации.
